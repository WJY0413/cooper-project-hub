# Cooper Project Hub

A reviewed public snapshot of 22 Feishu articles covering B2B channel research, sales operations, reusable skills, and troubleshooting. Snapshot date: 2026-10-15.

Browse the [complete directory](README.md): 22 corresponding articles, one supplemental release page, ten downloadable ZIP packages, and three header-only CSV templates.

The first section contains anonymized methodology adaptations, not verbatim client reports. Identifiable customers, people, contact routes, commercial terms, and internal records are excluded. Other articles preserve the shared workflows with explicit dependency and version notes. The historical LinkedIn People Search package was unavailable; its article explains the gap and links a newer workflow with different capabilities.

Workbench installers remain in the [original public releases](https://github.com/WJY0413/overseas-marketing-workbench/releases). The [sales library starter](https://github.com/WJY0413/sales-library-starter) also has a standalone repository.

This is not a live or automatic mirror. See [sync policy](SYNC_POLICY.md), [review record](PUBLIC_REVIEW.md), and [manifest](manifest.json).
