# 销售资料库自建 Skill｜三库与 Odoo

公开同步快照：2026-10-15。保留原文工作方法；附件与企业依赖的调整见文末。

[返回项目目录](../README.md)

这份自建包供同事用自己的资料与账号，逐步建立知识库、料号库和价格库，并让 AI 协助查询与操作自己的 Odoo。文末附完整 ZIP，解压后即可查看 Skill、空数据库、配置模板和使用说明。

**版本：**2026-10-15。包内没有预填企业业务数据、客户、真实报价、内部源链接或登录凭证。使用者需要配置自己的数据来源和权限。

## 能用来做什么

- **知识库：**整理文档摘要、原始链接和版本，回答时能回到原文核对。
- **料号库：**整理产品料号、市场版本、搭配规则和停用状态。
- **价格库：**按市场、币种、数量档位和有效期核对价格，保留证据位置。
- **Odoo：**查询客户、产品、价格和库存；准备报价或 PI；经明确授权执行单据操作，并查回核对结果。

## 下载后如何开始

1. 下载文末的 Sales-Library-Starter-20261015.zip，解压到自己的工作目录，先打开 README.md。
2. 将 skills/sales-library-workspace 文件夹复制到 AI 客户端的 skills 目录。Codex 常用位置是用户目录下的 .codex/skills/。已有同名 Skill 时先比较、备份，不直接覆盖。
3. 让 AI 打开解压后的工作目录，调用 $sales-library-workspace。也可以让支持读取 Markdown 的 AI 直接阅读包内 SKILL.md。
4. 本地脚本需要 Python 3.10 或更高版本。包内已有空 SQLite 库，不需要再初始化；在包目录运行下方命令，七张表应全部为 0。

```bash
python scripts/library.py status
```

不熟悉命令行时，可直接让 AI 在该工作目录执行检查。仅安装 Skill 不会自动接通任何企业系统。

## 可直接复制给 AI 的启动提示词

> 使用 $sales-library-workspace，从当前目录的空库开始。先检查我提供的资料与已登录系统，协助绑定知识、料号和价格来源，再验证一次读取。Odoo 先做只读能力检查，列出可用的查询和单据操作。不要导入示例业务数据。配置完成后，请说明哪些来源已读通、哪些字段还需要我确认。

## 绑定自己的原出处

把 config/sources.example.json 复制为 config/sources.json，填写自己的文档或表格链接。表格还需配置子表 ID 和读取范围，具体格式见 Skill 的 references/sources.md。飞书来源需要可用的 lark-cli 和本人账号权限；本包不包含 CLI 安装程序或其他人的登录状态。

```bash
python scripts/library.py refresh --source YOUR_SOURCE_ID
```

刷新脚本会读取原出处并保存当前快照。来源快照与整理后的业务记录分开：产品、知识摘要和价格仍需核验后入库。PDF 价格目录应先重新读取目录，再定位当前附件；文件刚更新也可能仍是过期报价，不能只看下载成功。

默认采用使用时按需读取，没有后台定时同步或事件推送。同事必须拥有原库访问权限；无权限或刷新失败时，旧缓存不会变成最新数据。

## 接入 Odoo

把 config/odoo.example.json 复制为 config/odoo.json，填写自己的实例、公司、版本及访问方式。由 AI 根据当前实例确认字段和企业模板，凭证使用现有连接器或系统凭证管理，不写进配置文件。

Odoo 模块提供 agent 操作流程，依赖所在环境的连接器或已登录浏览器，没有捆绑通用 API 写入程序。客户、产品、价格和库存可先做只读验证；创建或修改单据、提交、确认订单、开票、发货和外部发送，按使用者明确授权的范围执行。工具超时先查回，不盲目重复创建。
