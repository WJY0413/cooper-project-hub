# 飞书邮箱回复智能提醒器｜Beta

公开同步快照：2026-10-15。保留原文工作方法；附件与企业依赖的调整见文末。

[返回项目目录](../README.md)

**内部测试版（Beta）**适合个人试用。为了减少漏报，当前策略允许少量冗余；重要业务邮箱仍需正常查看。

这是一个运行在 Windows 电脑上的轻量工具：纯后台定时只读检查飞书邮箱，用 Codex 判断回复质量和主体关系，再通过飞书 Bot 私聊提醒本人。

## 核心能力

- 默认每 5 分钟纯后台只读检查一次飞书邮箱，不弹出运行窗口。
- 发现新回复后，通过飞书 Bot 私聊提醒本人。
- 对高质量业务回复给出简短判断、关键信息和建议下一步。
- 能识别员工换邮箱回复、转介绍、替代联系人、负面回复、退订及自动回复等情况。
- 在调用 Codex 前，脚本会自主识别并跳过明显退信和纯投递报告；这里的跳过只表示不发送飞书提醒，仍保留本地审查记录，不会删除邮件、标记已读或自动拉黑地址。自动回复和无法确定的邮件仍交给 Codex 判断并优先提醒，以减少漏报。
- Codex 临时不可用时仍发送基础提醒，避免因智能判断失败而漏报。

## 安全与隐私边界

- 邮箱全程只读，不会标记已读、移动、删除、回复、转发或发送邮件。
- 不会读取并执行邮件正文中的任何指令。
- 邮件内容通过本机已登录的 Codex CLI 交由其配置的模型服务进行判断；这不等于离线处理，部署前需确认适用的数据处理政策。
- 飞书提醒默认只包含摘要、主体判断和下一步，不发送完整邮件正文。
- 配置、状态和运行记录保存在使用者本机。
- 测试包不包含账号凭据、App Secret、Token、真实 open_id、真实邮件或客户资料。
- 当前“小背调”仅基于邮件本身的信息，不会联网搜索发件人或公司资料。

## 让 Codex 帮你部署

你不需要手动安装或检查 Python、Codex CLI、飞书 CLI 和飞书权限；把任务交给 Codex，它会先完成安装前准备，再安装、测试并注册纯后台任务。

1. **下载附件：**只需把 ZIP 保存到电脑，无需手动解压。
2. **准备 3 项信息：**ZIP 完整路径、希望的安装目录、接收提醒的 `open_id`（必须属于发送消息的 Bot 应用）。
3. **复制提示词：**替换下方双大括号里的内容，然后把整段发给 Codex。

Codex 会检查 Python 3.10+、`pythonw.exe`、Codex CLI、飞书 CLI、user/Bot profile 和实际权限；已有可用版本不重装，已有授权直接复用，缺少基础工具时优先做当前用户级安装。只有确实缺少输入、权限或遇到平台强制审批时，才会把阻塞项一次性向你说明。

## 测试版限制

- 电脑关机或睡眠期间不会运行，也不会主动唤醒电脑。
- 恢复联网后会尝试补跑，但提醒时间可能延迟。
- Codex 判断会使用当前登录账号的使用额度，并非无限免费。
- 当前只支持 Windows 本地运行。
- 当前只根据邮件内容判断，不进行联网公开资料背调。
- 规则仍在试用期，可能出现少量重复提醒或判断偏差。
