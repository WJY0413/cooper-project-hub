# Cooper Project Hub

海外 BD、渠道研究、销售自动化与 Codex 工作流的公开分享目录。

本仓库是飞书项目目录及对应内容的 **2026-10-15 人工审核公开快照**：22 篇对应文章、1 篇补充发布入口、10 个分享 ZIP、3 个空白 CSV。正文与附件均在本仓库中，Workbench 安装包链接到其公开 Release。

第一部分为脱敏方法版，保留研究结构与可复用方法，不公开真实客户、人员、联系方式、商务条款或可识别组合细节；不是原文逐字镜像。其他部分保留工作方法并注明依赖、历史版本和缺失附件。原始飞书文档未被修改。

## 使用方法

先阅读对应文章，再下载配套 ZIP 并阅读包内 README 和 SKILL.md。按自己的账号、环境和业务目标配置；旧版集成包不保证独立运行。外部发送、账户授权和生产写入按使用者自身规则确认。

销售资料库亦有[独立仓库](https://github.com/WJY0413/sales-library-starter)。本仓库未配置自动同步；后续内容变更需重新导出、脱敏和验证后提交。
